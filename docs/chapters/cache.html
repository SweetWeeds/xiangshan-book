CHAPTER 08 / 실험 03

캐시와 주소 변환

작은 캐시로 지역성을 관찰하고 TLB와의 차이를 익힙니다.

약 10분 · Kunminghu V2 문서 기반 · 개념 학습

01자주 쓰는 데이터를 가까이 둔다

캐시는 데이터의 일부를 가까운 저장 공간에 유지합니다. 최근 읽은 위치를 다시 읽는 시간 지역성과, 그 주변을 읽는 공간 지역성을 활용합니다. 적중하면 먼 메모리까지 갈 필요가 줄지만 모든 접근이 적중하는 것은 아닙니다.

02같은 위치를 놓고 경쟁할 때

아래는 4개의 라인과 라인당 16바이트를 가진 직접 사상 캐시 모형입니다. 블록 번호를 4로 나눈 나머지가 인덱스가 됩니다. 주소 0과 64를 번갈아 읽으면 같은 라인을 교체하며 충돌 미스가 발생합니다. 실제 XiangShan의 크기·연관도·지연을 재현하지는 않습니다.

03TLB는 데이터 캐시가 아니다

프로그램의 가상 주소를 물리 주소로 바꾸려면 주소 변환이 필요합니다. TLB는 이 변환 정보를 캐시합니다. TLB 미스는 데이터 캐시 미스와 다른 사건입니다. 둘 중 하나만 보아서는 메모리 접근이 느려진 이유를 충분히 설명할 수 없습니다.
